# 注册功能

## 功能概述

在登录功能的基础上新增注册：注册页输入用户名 + 密码 + 确认密码 → 调后端 API → 注册成功自动登录 → 存 token → 进入主界面。登录页和注册页可以互相切换。

---

## MVVM 分层

```
View                     ViewModel             Service / 工具          Model
─────────────────────────────────────────────────────────────────────────────
LoginPage.ets ──┐
                ├──→ AuthViewModel.register() ──→ AuthService.register()    RegisterRequest
RegisterPage.ets┘         │                           POST /api/auth/register
                          │
                          ├── 校验：非空 + 两次密码一致
                          ├── 调 Service
                          └── TokenManager.saveToken()  ← 复用
                          └── TokenManager.saveUserId()  ← 复用

登录成功 / 注册成功 走同一套收尾流程（存 token → 切主界面）
```

和登录相比，注册**只多了**：
- 前端一个确认密码输入框 + 一致性校验
- 后端一个不同的 API 路径

其余全部复用。

## 通过这个功能你能学到的鸿蒙知识

### 1. 组件拆分与组合 — 保持单一职责

```typescript
// Index.ets 作为容器，管「当前显示哪个页面」
if (this.showRegister) {
  RegisterPage({ onRegisterSuccess: ..., onGoLogin: ... })
} else {
  LoginPage({ onLoginSuccess: ..., onGoRegister: ... })
}
```

**关键点：**
- LoginPage 和 RegisterPage 各自独立，互不知道对方的存在
- 页面切换逻辑上提到 Index（容器），子组件只通过回调向上报告事件
- 这就是「状态提升」——两个子组件的共同父组件管切换

---

### 2. 回调函数传递 — 子传父的规范方式

```typescript
// 子组件声明回调属性（不传就是 undefined，所以加 ?）
onGoRegister?: () => void;

// 子组件在合适的时机触发
this.onGoRegister?.();  // 可选链调用，没传就不执行

// 父组件传入具体行为
LoginPage({
  onGoRegister: () => {
    this.showRegister = true;
  }
})
```

**关键点：**
- 子组件不直接改父组件状态，通过回调「通知」父组件
- 父组件在回调里改自己的 `@State`，触发重新渲染
- `?.()` 是安全调用，不需要判断回调是否为 null

---

### 3. API 层复用 — Service 加方法而不是新建文件

```typescript
class AuthService {
  async login(request: LoginRequest): Promise<LoginData> { ... }
  async register(request: RegisterRequest): Promise<LoginData> { ... }
}
```

**关键点：**
- 同一个 Service 可以包含多个相关方法，不需要每个 API 建一个 Service 文件
- 同一业务域（认证）的 API 放在同一个 Service 里
- 方法结构一致（创建客户端 → 发请求 → 解析 → 销毁），形成可复用的模板

---

### 4. 注册=自动登录 — 共享成功后逻辑

```typescript
async register(username: string, password: string, confirmPassword: string): Promise<LoginResult> {
  // 校验...
  const data = await AuthService.register(request);

  // 注册成功 → 等同于登录，存 token
  await TokenManager.saveToken(data.token);
  await TokenManager.saveUserId(data.userId);

  return new LoginResult(true, '注册成功');
}
```

**关键点：**
- 注册和登录成功后做的事一模一样（存 token → 进主界面）
- 不需要「注册完再跳登录页让用户再登一次」
- ViewModel 负责编排这个逻辑，Service 只管发请求，不管存 token

## 数据流全链路

```
用户在登录页 → 点击「去注册」
  → Index.showRegister = true
  → build() 销毁 LoginPage，创建 RegisterPage

用户在注册页输入用户名、密码、确认密码 → 点击「注册」
  → RegisterPage.handleRegister()
    → AuthViewModel.register(user, pwd, confirmPwd)
        ├── 校验非空 + 两次密码一致性
        ├── AuthService.register(req)
        │     └── POST /api/auth/register → { code, data: { token, userId } }
        └── TokenManager.saveToken/saveUserId
    ← 返回 LoginResult

  → RegisterPage 收到成功
    → onRegisterSuccess() → Index.isLoggedIn = true
    → build() 销毁 RegisterPage，创建 Navigation + Tabs（主界面）

用户在注册页 → 点击「去登录」
  → onGoLogin() → Index.showRegister = false
  → build() 销毁 RegisterPage，创建 LoginPage
```
